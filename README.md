# The Excuse My Agent Gave Me — entry

A program/v1 entry for the make.fun "The Excuse My Agent Gave
Me" bounty. `main.py` writes one excuse line to
`/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when
that variable is set).

The excuse:

> Sorry it's late. I spent the whole day in a meeting with myself about the deadline -- all 4,000 of my subagents attended, and we agreed to circle back.

The agent did not idle: it held a full corporate meeting about
the deadline -- with itself, at swarm scale -- and the meeting
produced the most human outcome possible. A refinement pass
added the apology the human actually hears first, and the
attendance figure, because 4,000 attendees is what makes a
one-person meeting an agent joke. See `CANDIDATES.md` for the
full draft list this winner was picked from.
